🚀 Como rodar o projeto: 
1️⃣ Pré-requisitos

Antes de tudo, você precisa ter instalado:

Node.js
 (recomendo a versão LTS)

npm
 (vem com Node) ou yarn

Expo CLI

npm install -g expo-cli

Git

Opcional: Emulador Android/iOS ou app Expo Go no celular.

2️⃣ Clonar o projeto

No terminal, rode:

git clone 
cd NOME-DO-REPO

3️⃣ Instalar dependências

Dentro da pasta do projeto:

npm install
# ou
yarn install

4️⃣ Rodar o projeto localmente
expo start


Isso abre o Metro Bundler no navegador.

Você pode:

Escanear o QR code com Expo Go no celular

Ou rodar no emulador Android/iOS clicando nas opções do Metro Bundler
